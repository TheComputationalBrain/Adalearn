## **Project**

This repository contains essential elements for running and analysing the studies within the ADALEARN project. The ADALEARN project seeks to understand mechanisms driving adaptive changes in learning rate within a dynamically changing probability learning task. The primary investigated mechanisms focus on the role of neuromodulators and specifically noradrenaline. The project contains 3 studies: ADALEARN: Pupil, ADALEARN: VNS, ADALEARN: Atomoxetine.

## **Analysis**

The analysis folder is structured as follows: The top level contains functions used for analysis across all studies. Study specific folders represent the second level. In each folder, scripts call functions for the specific analysis of that study. In each study specific folder, analysis scripts are generated to perform analysis at both a participat level and group level. To obtain the presented study outcomes, participant level analysis can be ignored, with only group level scripts required.
